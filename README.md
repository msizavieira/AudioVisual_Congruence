# The Impact of Audio-Visual Congruence on Navigation, Immersion and Stress Reduction in Virtual Environments

This repository contains the Unity project and supporting materials for an academic research project investigating the role of **audio-visual congruence** in Virtual Reality (VR) navigation experiences. The project explores how the alignment (or misalignment) between auditory and visual cues affects **navigation performance**, **immersion**, and **presence** in a maze-based virtual environment.

The system was developed using **Unity** and **FMOD**, targeting standalone VR headsets (Meta Quest). Soundscapes are treated as navigational landmarks and are spatially integrated into the environment using real-time audio occlusion and attenuation techniques.
